# Contributing

Commit messages, pull request titles, pull request descriptions, and GitHub Release notes are written in English.

User-facing copy is added in both English and Turkish through `L10nKey`. Patch notes are not translated per language. The in-app history shows the English release text.

## Pull requests

Describe what changed and how to test it. Use the pull request template.

## Releases

Follow [docs/RELEASING.md](docs/RELEASING.md). The release body is the patch notes a user reads in the app.
